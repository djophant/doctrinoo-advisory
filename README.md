# Doctrinoo Advisory - GitHub Pages

Ce dossier contient une version statique du site Doctrinoo Advisory, prête pour GitHub Pages.

## Fichiers

- `index.html` : page principale du site
- `styles.css` : design du site

## Publication gratuite avec GitHub Pages

1. Créer un compte GitHub si nécessaire.
2. Créer un nouveau repository, par exemple `doctrinoo-advisory`.
3. Mettre le repository en `Public` si vous voulez utiliser GitHub Pages gratuitement.
4. Ajouter les fichiers `index.html` et `styles.css` à la racine du repository.
5. Aller dans `Settings`.
6. Aller dans `Pages`.
7. Dans `Build and deployment`, choisir :
   - Source : `Deploy from a branch`
   - Branch : `main`
   - Folder : `/root`
8. Cliquer sur `Save`.

Après quelques minutes, GitHub donnera une adresse du type :

`https://votre-nom-utilisateur.github.io/doctrinoo-advisory/`

## Important

GitHub Pages est gratuit pour les repositories publics. Si vous voulez un repository privé avec GitHub Pages, les conditions peuvent dépendre de votre compte GitHub.

Pour rester gratuit, le plus simple est :

- repository public ;
- site statique ;
- pas de serveur ;
- pas de base de données ;
- pas de fonctionnalité payante.
